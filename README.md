# ЛР1 - Каталог картин современного искусства

У каждой картины есть изображение, название, автор, год написания и стоимость.

Картины можно добавлять и удалять из корзины. Каждую картину можно добавить в корзину только 1 раз

Корзину можно открывать и закрывать

Нельзя оформить заказ из 0 картин
